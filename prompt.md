# Основной проект: Thunderbird extension HuNote

Создай расширение (`extension`) для `Thunderbird` фактически копирующее функциональность `QNote`, по добавлению заметок к почтовым сообщениям. Давай назовёт его `HuNote` (или полностью Hubbitus Notes).

Основные требования:
1. Основной дизайн и элементы управления можно взять у `QNote`, но заметки давай сделаем светло-зелёными
2. Самое важное, сама введённая заметка должна сохраняться на сервер по протоколу `IMAP`, в заголовок сообщения: `X-Hu-note`!
    * При этом, в заголовок `X-Hu-note-timestamp` должна писаться полная дата, с точностью до миллисекунд, в формате `ISO-8601`.
    * В заголовок `X-Hu-note-source` записываем идентификатор устройства (`hostname`) откуда оно сохранено.
3. При редактировании сохраняем все версии в заголовок `X-Hu-note-versions`, с датой каждой версии.
    * Реализуй возможность их просмотра, с указанием даты изменения.
    * Реализуй возможность просмотра визуального отображения, что изменилось (`diff`)
4. Расширение должно использовать последнюю, 3 версию манифеста и быть совместимо с `Thunderbird` версии 140+
5. Должен назначаться `хот-кей` для добавления заметки. `Хот-кей` не хардкодится, должно быть можно переопределить в настройках. `Ctrl + Shift + N` по умолчанию.
6. Добавь возможность фильтрации, по наличию такого сообщения (как есть фильтрация "с аттачментами")
7. В гриде (таблице) сообщений должна быть возможность отобразить колонку "с заметками" (также по примеру аттачей).
8. Добавь возможность поиска по тексту внутри заметок и по их датам. По датам реализуй операторы `>`, `<`, `>=`, `<=`.
9. Добавь страницу настроек проекта. Настройки должны сохраняться сразу, без кнопки сохранения. Должно быть визуальное отображение факта, что сохранение произошло.
    * Вынеси туда максимальную длину заметки. По-умолчанию 1000 символов. В окне редактирования показывай длину вводимого сообщения (при наборе) и доступный максимум.
    * Реализуй возможность включения и отключения записи `X-Hu-note-source`.
    * В окне настроек реализуй мастер (`wizard`) импорта имеющихся заметок из расширений `QNote` и `XNote`, если они установлены.
10. Обязательно подготовь простой `Makefile` для сборки итогового архива.
11. Добавь `README.md` с инструкциями и описанием. В том числе описание как локально для разработки запустить проект и отлаживать его (на `Linux` основное, другие системы можно упоминать коротко, если есть какие-то отличия).
12. Добавь авто-тестирование, на сколько это возможно. С описанием как авто-тесты запустить.
    * С подсчётом покрытия (`coverage`).
13. Добавь `github actions` для сборки и тестирования проекта автоматически в рамках CI/CD.


Скажи, если нужны референсы на код расширений для сохранения заголовков или `QNote`.
